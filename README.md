# SlowBroom

A small, quiet browser game: mop a dusty floor, sort a forest floor as an ant, or lay mosaic tiles.
Arrow keys only. Nothing to score, nothing to lose.

Play: https://schakka96.github.io/slowbroom/

Inspired by [Hozy](https://store.steampowered.com/app/3326230/Hozy/) and
[The Sorting Bureau](https://store.steampowered.com/app/4120790/The_Sorting_Bureau/) — both
made with far more love than this one. Go play those.

## Controls
- **Arrow keys** — move
- **1–4** — speed
- **− / +** — mop width, or the ant's size
- **Space** — pause (mopping/mosaic), set down a pile (ant)
- **Type a letter** — write a chat message right on the field, Enter sends

## Notes
Single file, no build, no dependencies: `index.html`. The live player count and the chat only
work on the claude.ai-hosted copy, which provides those services; here the page runs solo.
